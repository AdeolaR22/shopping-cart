# Shopping Cart Project

## About the Project

This is a simple Shopping Cart project built with HTML, CSS, and JavaScript.

The project allows users to interact with products in a shopping cart and see how the total price changes when they update their cart.

## Features

- Increase product quantity.
- Decrease product quantity.
- Delete products from the shopping cart.
- Like products using a heart button.
- Automatically calculate the total price.
- Responsive layout for smaller screens.

## Technologies Used

- **HTML:** Used to structure the shopping cart.
- **CSS:** Used to style the webpage.
- **JavaScript:** Used to make the shopping cart interactive.

## Project Structure

- `index.html` – Contains the HTML structure.
- `style.css` – Contains the styling.
- `script.js` – Handles the shopping cart functionality.
- `README.md` – Contains information about the project.

## How to Run the Project

1. Download or clone the project.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` in your browser.
4. Click the plus, minus, heart, and delete buttons to test the features.
